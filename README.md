le projet consistait à réaliser un porte folio demander par un camarade de classe,

 Le client (camarade de classe) nous as demandé de créer un site permettant à son recruteur ou à un utilisateur dès qu'il arrive sur la page d'accueil, il aura accès à une page d'accueil qui comporte 4 bloc, chaque bloc est nommé (projet 1, 2, 3 et About me), Chacun de ses bloc permet d'avoir un résumé du projet ou des informations concernant le client.

Les blocs sont cliquable pour permettre de naviguer à une autre page pour permettre d'avoir la description du projet au complet, par exemple lors ce que on clique sur le bloc projet 1 on accède à une page qui contient la description du projet 1 détaillé. le client nous as aussi demandé de faire un menu de navigation contenant plusieurs boutons : Projet 1, Projet 2, Projet 3, Projet 4 et about me, chaque bouton permet de naviguer aussi sur les pages des projets en détaillé.


pour réaliser le site nous avons utilisé plusieurs langages de programmation notamment le HTML, le css et le java script.
 
Le projet a été réalisé en équipe avec une répartition des tâches entre les trois membres : Luc pour le HTML, Massoudou pour le CSS et Yannis pour le JavaScript.

Pour la partie HTML, elle a servi principalement pour créer la structure des différents pages du portefolio, comme les menu, les descriptions, les titres, les boutons et les différents pages. Pour la partie CSS, Elle a servi pour le design général afin de rendre le portfolio plus agréable et moderne, le client n'avait pas demandé de couleur spécifique ni de design spécifique donc nous avons décider de le faire nous meme. Pour la partie Java script, elle a servi pour ajouter les interactions et les fonctionnalités dynamiques du site.
